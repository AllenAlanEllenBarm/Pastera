# 主菜单快捷键与片段数字导航设计

## Goal

让主菜单、历史翻页和片段选择形成稳定且可预测的键盘入口：

- `⇧⌘V` 主菜单快捷键始终打开历史，不恢复上次停留的片段或密码页面。
- 历史上一页、下一页固定使用裸 `←`、`→`，不再作为可录制快捷键。
- 片段默认快捷键改为 `⇧⌘M`，并支持“数字选文件夹，再按数字选片段”的两阶段操作。

## Scope

本设计覆盖全局菜单快捷键默认值与兼容迁移、统一主面板的入口模式、历史面板的本地翻页事件、快捷键偏好设置，以及片段树的数字标记和两阶段选择。

本设计不新增窗口或全局按键序列监听器，不改变历史和片段的复制/粘贴业务语义，不移除既有的文件夹独立全局快捷键，也不修改密码箱入口与身份验证流程。

## Interaction Model

### 主菜单入口

- 触发 `⇧⌘V` 后，统一主面板总是切换到历史模式再显示。
- 即使面板上次停留在片段、密码箱或密码箱子页面，也不得恢复该位置。
- 独立历史快捷键继续进入历史；片段和密码箱分别由自己的快捷键进入。
- 切换入口前沿用现有未提交编辑处理，不通过丢弃草稿来强制切换模式。

### 历史翻页

- 历史面板和统一主面板都使用裸 `←`、`→` 切换上一页、下一页。
- `⌘←`、`⌘→` 以及其它带业务修饰键的方向键不作为新的固定翻页键。
- 搜索框持有编辑焦点或正在进行输入法组合时，左右键由文本编辑器处理，不触发翻页。
- 快捷键偏好设置中删除“上一页”和“下一页”录制行，只保留历史搜索快捷键。
- 已保存的历史翻页快捷键数据不主动删除，但运行时不再读取或展示，因此不会覆盖固定方向键。

### 片段两阶段数字导航

1. 触发片段快捷键 `⇧⌘M`，统一主面板进入片段模式并从全部折叠的文件夹层开始。
2. 第一次按数字键，选择并展开该编号对应的启用文件夹；此次按键不得同时执行其中的片段。
3. 文件夹展开后再次按数字键，选择并执行该文件夹内对应的启用片段，沿用现有关闭面板、复制和粘贴目标处理。
4. 文件夹层和展开文件夹内的片段层都显示数字标记，数字映射与实际事件处理使用同一个映射器。
5. 默认编号为 `1` 至 `9` 对应前九项、`0` 对应第十项；若用户已启用“从 0 开始编号”，继续沿用 `0` 对应第一项的既有规则。
6. 超过十个文件夹或片段的项目不显示数字标记，也不能通过单个数字直接选择。
7. 搜索框、片段内联编辑器或文件夹快捷键录制器正在接收输入时，数字键不得触发文件夹或片段选择。

展开状态是两阶段导航的唯一状态来源：`expandedSnippetFolderID == nil` 表示文件夹选择阶段，有值表示片段选择阶段。关闭后重新通过片段全局快捷键打开时，继续使用现有逻辑将展开状态重置为空，不引入计时器、超时窗口或额外持久化状态。

## Architecture

### `HotKeyService`

- 将片段默认快捷键设为键码 `M` 的 `Shift + Command` 组合。
- 增加一次性迁移：只有当前保存值仍等于旧默认 `⌥⌘F` 时才改为 `⇧⌘M`；任何其它自定义值保持不变。
- “恢复菜单快捷键默认值”和旧格式默认字典统一返回 `⇧⌘M`。
- 将历史搜索保留为可配置的本地快捷键；上一页、下一页改为固定裸方向键，不再从用户默认值解析。

### `MenuManager` 与 `MainMenuPanelController`

- `MenuManager.popUpMenu(.main)` 在显示主面板前显式调用历史入口，使 `⇧⌘V` 不再继承控制器的 `selectedMode`。
- `MainMenuPanelController` 继续拥有片段展开状态和可见项目顺序。
- 片段内容构建时分别维护可见文件夹 ID 与当前展开文件夹的可见片段 ID；文件夹和片段使用同一数字映射规则。
- 数字处理先检查搜索和编辑状态，再按展开状态决定“展开文件夹”或“执行片段”，避免在行视图中复制事件逻辑。

### 偏好设置与历史面板

- `CPYShortcutsPreferenceViewController` 不再创建、刷新或处理上一页/下一页的 `RecordView`。
- 历史分页按钮的 tooltip 和辅助功能文本展示固定 `←`、`→`。
- 独立历史面板和统一主面板只在无业务修饰键且搜索框未编辑时消费左右方向键。

## Compatibility and Migration

- 用户自定义的片段全局快捷键不迁移。
- 使用旧默认 `⌥⌘F` 的现有安装会在一次性迁移后获得 `⇧⌘M`。
- 旧的历史翻页自定义值留在 `UserDefaults` 中但不再生效；本次变更不做破坏性配置清理。
- 文件夹独立全局快捷键继续注册和工作；两阶段数字导航只在已经打开的统一主面板内处理。
- 历史数字选择和片段数字选择继续遵守既有“从 0 开始编号”偏好。

## Error and Edge Handling

- 数字对应的文件夹或片段不存在、已禁用或超过可直选范围时，不执行动作，并允许事件按现有响应链继续处理。
- 空文件夹可以被数字键展开；展开后按数字不执行任何片段。
- 数据刷新导致已展开文件夹失效时，沿用现有逻辑回到文件夹选择阶段。
- 当前内联草稿无法提交时，模式入口不得静默丢弃草稿；保持现有错误反馈和编辑状态。
- 已到第一页或最后一页时，方向键事件可以被历史面板消费，但不得改变页码或产生额外错误。

## Acceptance Criteria

1. 面板上次停留在片段或密码箱后，触发 `⇧⌘V` 仍显示历史。
2. 独立片段快捷键默认显示并注册为 `⇧⌘M`；旧默认值会迁移，自定义值不会变化。
3. 历史偏好设置不再显示上一页、下一页录制项；历史搜索快捷键仍可配置和重置。
4. 历史主面板与独立历史面板均可使用裸 `←`、`→` 翻页，搜索编辑时左右键不会翻页。
5. 打开片段后按数字只展开对应文件夹，再按数字才执行该文件夹内的对应片段。
6. 文件夹与片段的数字标记、`1...9/0` 映射以及“从 0 开始编号”行为一致。
7. 搜索、输入法组合、片段编辑和文件夹快捷键录制期间，数字键不会误执行项目。
8. 现有文件夹独立快捷键、片段执行、历史数字选择、密码箱入口和面板关闭行为保持可用。

## Verification

- `HotKeyServiceTests` 覆盖新默认值、旧默认迁移、自定义值保护、恢复默认和固定历史方向键。
- `MenuManagerStatusItemTests` 或对应入口测试覆盖从片段、密码模式重新触发主菜单快捷键后回到历史。
- `MainMenuEmbeddedContentTests` 覆盖文件夹阶段、片段阶段、空文件夹、十项边界、从零编号和输入状态保护。
- 历史面板测试覆盖裸左右键、带修饰键不翻页、搜索框光标移动和分页边界。
- 快捷键偏好测试确认上一页、下一页录制控件已移除且重置只影响仍可配置的项目。
- 完成实现后执行聚焦测试、仓库默认 `xcodebuild ... clean test`、`git diff --check` 和 `./script/install_local.sh`，并在真实应用中手动验证三条键盘链路。

## Out of Scope

- 将数字序列注册为系统级全局热键。
- 为两阶段数字输入增加超时或 HUD。
- 移除或批量重写现有文件夹独立快捷键。
- 扩展到密码箱文件夹/条目的数字直选。
- 改变片段、历史或密码箱的数据模型、排序规则与同步协议。
