# 对应组件悬停快捷键提示设计

## 目标

移除主面板底部的“键盘快捷键”问号入口及其大型汇总面板。快捷键改为跟随对应组件，通过 macOS 原生悬停提示按需展示；主界面默认状态不增加新的文字、徽标或装饰。

## 交互设计

- 搜索按钮提示“搜索 · ⌘F”。
- 上一页、下一页等分页组件分别提示自身支持的方向键与 Control 键组合。
- 类型切换组件提示“切换类型 · Tab”。
- 可粘贴的内容行提示确认粘贴与纯文本粘贴快捷键；带数字直选能力的行同时提示其对应数字键。
- 历史、片段、密码箱等模式按钮只展示与该组件直接相关的名称或快捷键，不承载无关快捷键说明。
- 提示采用系统 tooltip 的延迟、材质、圆角和阴影，不自绘浮层，不改变组件布局，不在未悬停时占用空间。

## 实现边界

- 删除主工具栏中的快捷键按钮、按钮回调和大型快捷键 popover 视图。
- 复用现有 `toolTip` 与快捷键格式化能力，将文案挂到实际可操作控件和内容行。
- 无对应可见组件的全局行为不另外创建入口；快捷键设置仍由偏好设置中的快捷键页面负责。
- 不调整主面板配色、尺寸、信息架构或其它正在开发的功能。

## 可访问性

tooltip 文案同时作为对应控件的辅助功能标签或帮助文本；移除问号入口后，不移除键盘本身的操作能力。

## 验收

1. 主面板底部不再出现问号按钮，点击式大型快捷键面板不再存在。
2. 鼠标悬停搜索、分页、类型切换和内容行等对应组件时，可看到该组件相关快捷键。
3. 未悬停时界面没有新增常驻元素，工具栏布局自然、无突兀空洞。
4. 原有快捷键行为保持可用，相关测试和应用构建通过。
5. 运行真实应用并截图，确认默认状态简洁且提示位置不遮挡关键内容。
