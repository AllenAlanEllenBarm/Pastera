# Pastera 设置侧栏精修设计

## 目标

让设置窗口左侧菜单更接近 macOS 原生设置体验：克制、紧凑、易扫描，并使用更清楚的中文名称。

## 范围

- 将侧栏宽度调整为 188pt，使用 16pt 左右内边距，保持搜索框、分割线和菜单行对齐。
- 菜单行使用 40pt 高度、14pt Medium 字体；SF Symbol 以 Medium 描边在 20pt 视觉框内等比缩放，再放入 26pt 固定图标槽，形成稳定且不失真的图文间距。
- 选中态使用浅强调色背景和高对比度 `labelColor` 图标与文字；未选中态保持原生标签色。
- 不显示分组标题；两组菜单之间只使用 1pt 弱分割线和紧凑间距。
- 更新菜单名为“基础设置、历史记录、快捷键、忽略应用、云同步、关于”。
- 图标依次使用 `gearshape`、`clock.arrow.circlepath`、`keyboard`、`app.badge.checkmark`、`icloud`、`info.circle`。
- 快捷键页使用 38pt 紧凑设置行、24pt 记录框和 4pt 标题后间距，内容结束后至少保留 56pt 可视区底部空白。

## 不做范围

- 不修改右侧设置页的内容结构、业务逻辑或数据保存行为。
- 不引入自定义图片 Logo、第三方图标库、新窗口或全局主题。
- 不重做搜索交互、键盘导航和页面切换逻辑。

## 约束与影响面

- 继续使用 AppKit、Auto Layout、SF Symbols 和现有 `PasteraDesignTokens`。
- 保持 macOS 13+ 兼容性、键盘焦点、辅助功能标签和浅色/深色外观。
- 仅修改设置目录、侧栏组件、本地化文案及其回归测试，保留工作区其他未提交改动。

## 验收口径

- 中文菜单和分组名称与本设计一致，“同步”显示为“云同步”。
- 六个图标具有一致的 16pt 视觉框和稳定文字起始线，文字不截断。
- 菜单行高度、字体字重、圆角和选中态符合设计值。
- 两组菜单之间仅显示一条弱分割线，不出现“设置 / 其他”标题或大块空白。
- 右侧页面内容顶部使用 14pt 内边距，标题更靠近窗口内容区顶部。
- 设置窗口构建、相关自动化测试、安装启动均成功。
- 真实应用截图中，侧栏在深色或浅色外观下层级清晰、密度均衡、无溢出或错位。

## 验证映射

- Codex：目录文案、图标名和布局参数测试。
- Codex：Xcode 定向测试与完整构建。
- Codex：本机安装、启动和设置窗口截图回看。
- 用户：最终主观偏好与后续微调意见。

## 任务顺序

1. 先更新回归测试并确认针对旧实现失败。
2. 更新目录、本地化和侧栏视觉参数。
3. 运行测试、构建、安装并截图验收。
