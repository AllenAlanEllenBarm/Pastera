# 脚本设置紧凑布局设计

## 目标

在不改变脚本管理、测试和快捷键功能的前提下，减少“设置 → 脚本”页面的无效留白，使页面与 Pastera 其余设置页保持统一、紧凑、清晰的桌面设置风格。

## 已确认方向

采用紧凑双区布局：

1. 顶部为“转换脚本”区，承载脚本列表及创建入口。
2. 下方为一张共享外框的工具卡片，左侧为“测试脚本”，右侧为“全局快捷键”。

不采用三个纵向大卡片，也不把全部内容压进缺少层级的单一面板。

## 页面结构

### 转换脚本区

- 保留图标、标题和一句简短说明。
- 无脚本时不再使用 220pt 的最低高度；空状态以一行状态文案和紧凑按钮组呈现。
- “新建脚本”为主按钮，“从模板创建”为次按钮，二者位于同一操作行。
- 有脚本时继续显示脚本行列表，行高、圆角和操作按钮沿用现有设置组件风格。
- 脚本数量增加时由页面滚动承载，不恢复大面积占位。

### 测试与快捷键工具卡片

- 两个功能共享同一外框和背景，以细分隔线区分，不形成两张相互割裂的大卡片。
- 左侧测试区占可用宽度的主要部分：脚本选择器、测试输入和“运行测试”组成紧凑操作行，结果显示在其下方。
- 右侧快捷键区保持窄栏：标题、简短说明和快捷键录制控件纵向排列。
- 窄窗口下允许工具卡片改为上下排列，控件不得裁切或溢出。

## 视觉规格

- 页面模块间距：16pt。
- 卡片内边距：16pt；紧凑子区间距为 8–10pt。
- 卡片圆角、边框颜色和背景继续复用现有设置页样式。
- 一级页面标题保持现状；卡片标题统一为 15–16pt semibold，正文和帮助文案使用 secondary label color。
- 输入框、选择器、按钮和快捷键录制控件在同一操作行内保持中心线一致。
- 文案保持短句，不重复解释已经由控件名称表达的内容。

## 状态与交互

- 无脚本时，测试选择器与运行按钮禁用，并显示“请先创建脚本”的紧凑提示。
- 有脚本时，选择器展示已保存脚本；运行测试继续调用现有真实 JavaScript 执行链，且不修改剪贴板。
- 成功结果使用系统绿色，失败结果使用系统红色；结果区域只在需要时占用高度。
- 新建、模板市场、编辑、启用、删除和快捷键录制行为保持不变。

## 验收标准

1. 无脚本实机截图中，顶部卡片不再出现大块空白，主要操作无需滚动即可看到。
2. 测试与快捷键呈现为一张共享卡片，层级和间距与其他设置页一致。
3. 页面不存在控件裁切、横向溢出、文字压线或明显失衡的空白。
4. 有脚本和无脚本状态都能正常布局；测试脚本成功与失败行为不回归。
5. 相关单元测试、设置窗口交互测试和 macOS 构建通过。
6. 安装到 `/Applications/Pastera.app` 后，以真实设置窗口截图完成最终视觉验收。

## 范围边界

- 本次仅调整脚本设置首页布局与样式，不重做模板市场或脚本编辑器。
- 不修改脚本数据模型、执行语义、持久化格式或快捷键业务逻辑。
- 不引入新的设计系统、依赖或独立窗口类型。
