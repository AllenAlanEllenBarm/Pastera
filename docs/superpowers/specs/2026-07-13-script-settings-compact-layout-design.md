# 脚本设置与二级测试窗口设计

## 目标

参考 OneClip 的实际脚本管理与测试交互，重新整理“设置 → 脚本”的信息层级。在保留脚本管理、脚本测试和全局快捷键能力的前提下，让首页只承担高频管理任务，把需要较多输入空间的测试流程放入二级窗口，避免控件横向堆叠和卡片过度压缩。

## 交互参考与设计结论

实际操作 OneClip 后确认，其脚本首页负责列表管理和创建入口，脚本编辑与测试在独立的二级界面中纵向展开。Pastera 采用相同的信息分层原则，但不照搬视觉细节：

1. 脚本首页聚焦脚本列表、创建、导入和进入测试。
2. 测试脚本通过二级 Sheet 打开，输入、执行和结果纵向排列。
3. 全局快捷键保持为首页下方的独立轻量设置行，不与测试功能拼成左右双栏。

废弃此前“测试脚本与全局快捷键共享一张左右并排工具卡”的方案。该方案在设置窗口宽度下会压缩选择器、输入框和快捷键说明，造成拥挤且削弱功能层级。

## 首页结构

### 转换脚本管理卡片

- 保留图标、标题和一句简短说明。
- 无脚本时使用 120–150pt 的适度留白，居中展示“暂无脚本”和操作入口；既不恢复原来的大面积空白，也不压缩成单行工具条。
- 操作区位于卡片底部，包含“新建脚本”“从模板创建”“导入”和“测试脚本”。
- “新建脚本”为主操作，其余为次操作；“测试脚本”在没有可用脚本时禁用。
- 有脚本时显示现有脚本列表，继续提供启用、排序、编辑和删除操作；操作区保持在列表下方。
- 脚本数量增加后由设置页面滚动承载，不固定放大卡片高度。

### 全局快捷键设置行

- 位于脚本管理卡片下方，使用独立的轻量设置行或小卡片，不与测试区共享外框。
- 左侧为标题和一句说明，右侧为快捷键录制控件。
- 行高以完整容纳说明和录制控件为准，不增加装饰性大留白。
- 快捷键录制、冲突处理和持久化逻辑保持不变。

## 二级测试窗口

点击“测试脚本”后，以当前设置窗口为父窗口打开 Sheet。测试窗口使用单列纵向布局，避免把多个输入控件压在同一行。

### 窗口结构

1. 顶部显示“测试脚本”标题、简短说明和“完成”关闭按钮。
2. 脚本选择器占满内容宽度，展示已保存且可执行的脚本。
3. 测试输入使用全宽多行文本区域，允许粘贴和编辑较长内容。
4. “运行测试”为明确的主按钮，放在输入区下方靠右或居中位置。
5. 执行后在按钮下方显示结果区域；没有结果时不保留大块空白。

### 状态与反馈

- 打开窗口时默认选择最近选择的脚本；没有历史选择时选择第一个可用脚本。
- 执行继续调用现有 `ScriptExecuting` 真实 JavaScript 执行链，不修改系统剪贴板，也不自动粘贴。
- 执行期间禁用重复提交，并显示明确的进行中状态。
- 成功结果使用成功图标、状态文案和系统绿色；失败结果使用错误图标、错误文案和系统红色，不能只依赖颜色区分。
- 输入为空、脚本不可用或执行失败时，在结果区域给出可理解的原因。
- 支持键盘焦点顺序；关闭、脚本选择、输入和运行按钮应提供清晰的辅助功能标签。

## 视觉规格

- 首页模块间距：16–20pt。
- 卡片内边距：16–20pt；同组控件纵向间距：10–12pt。
- 空状态保持 120–150pt 的视觉呼吸空间。
- 测试 Sheet 使用舒展的单列布局，内容边距为 20–24pt，输入区域不得与脚本选择器或运行按钮横向挤压。
- 卡片圆角、边框、背景色、按钮层级和字体继续复用现有 Pastera 设置界面样式。
- 文案使用短句；标题、说明、控件标签和结果反馈应形成明确层级。

## 技术边界

- 新增独立的脚本测试 Sheet/controller，首页只保留打开入口和快捷键设置。
- 复用现有脚本存储、脚本执行和快捷键业务逻辑。
- 不修改脚本数据模型、持久化格式或执行语义。
- 不重做脚本模板市场和脚本编辑器；只保证它们仍可从首页正常进入。
- 不增加第三方依赖，也不引入与测试流程无关的新窗口。

## 验收标准

1. 无脚本首页保留适度留白，创建入口清晰，不再出现过度空旷或过度压缩。
2. 有脚本首页能清晰展示脚本列表和底部操作区，控件无裁切、溢出或文字压线。
3. 全局快捷键作为独立轻量设置行展示，不与测试功能形成拥挤的左右双栏。
4. “测试脚本”从首页打开二级 Sheet；选择器、输入区、运行按钮和结果按单列顺序展示。
5. 测试成功、测试失败、空输入和无可用脚本状态都有明确反馈，且测试过程不修改剪贴板。
6. 相关单元测试、设置窗口交互测试和 macOS 构建通过，运行时无 Auto Layout 冲突。
7. 安装到 `/Applications/Pastera.app` 后，分别截取无脚本首页、有脚本首页、测试窗口初始态、成功态和失败态进行真实视觉验收。

## 范围边界

- 本次调整脚本设置首页、测试入口和二级测试窗口。
- 模板市场与脚本编辑器的内容和交互不在本次重设计范围内。
- 不改变脚本执行结果写回剪贴板的既有业务边界；测试路径始终只返回预览结果。
