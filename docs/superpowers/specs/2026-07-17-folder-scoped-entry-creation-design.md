# 文件夹层级内条目创建设计

## 交互规则

- 密码箱和片段只在编辑模式显示创建入口，并且任意时刻最多显示一个“+”。
- 所有文件夹关闭时，“+”位于全部文件夹之后，与文件夹图标左边缘对齐；点击直接创建根级文件夹。
- 某个文件夹展开时，根级“+”消失；子级“+”位于该文件夹最后一个条目之后、下一个文件夹之前，并与条目图标左边缘对齐。
- 展开文件夹内的“+”点击后直接创建密码或片段，不显示“新建文件夹/新建条目”菜单。
- 空文件夹展开时，子级“+”紧跟文件夹行。切换展开文件夹时，“+”随当前文件夹移动；收起后恢复为根级“+”。
- 搜索状态不显示创建入口，避免自动展开的搜索结果被当作用户选中的创建目标。
- 文件夹只允许一层。根级“+”是唯一的文件夹创建入口，文件夹拖放只调整根级顺序。

## 布局语义

- 根级创建行复用文件夹行的 leading inset，使“+”与文件夹图标同列。
- 子级创建行使用一级缩进，使“+”与密码锁或片段条目图标同列。
- 创建编辑器在点击位置原地替换“+”；完成或取消后恢复对应层级的“+”。
- 图标按钮保留 tooltip 和 accessibility label：`新建文件夹`、`新建密码`、`新建片段`。

## 验收状态

- 非编辑模式：无“+”。
- 编辑模式、全部关闭：列表末尾只有根级“+”，直接创建文件夹。
- 编辑模式、空文件夹展开：文件夹内只有子级“+”，直接创建条目。
- 编辑模式、非空文件夹展开：子级“+”紧跟最后一个条目。
- 菜单完全移除，密码箱和片段行为一致。
