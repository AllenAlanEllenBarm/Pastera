# 移除“打开 Pastera”菜单项设计

## 目标

从状态栏图标的右键菜单中移除顶部“打开 Pastera”选项，消除与状态栏图标左键打开主面板能力重复的入口。

## 行为

- “历史”成为右键菜单第一项。
- “片段”“密码箱”及后续功能顺序不变。
- 保留“密码箱”之后的分隔线，菜单顶部不新增分隔线或空白。
- 状态栏图标左键仍打开 Pastera 主面板，右键仍打开上下文菜单。

## 实现范围

- 删除 `makeStatusItemContextMenu()` 中的“打开 Pastera”菜单项。
- 删除仅由该菜单项使用的 `openMainPanelFromContextMenu` 路由。
- 更新菜单顺序与路由测试，明确断言该选项不存在。

## 验收

1. 右键菜单中不存在“打开 Pastera”。
2. “历史”位于菜单首项，顶部无多余空白或分隔线。
3. 左键状态栏图标仍路由到主面板。
4. 相关测试和应用构建通过。
