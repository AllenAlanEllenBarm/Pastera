# Pastera 主面板 C1 克制玻璃设计

## 方向

主面板采用克制的深色玻璃工具面板。强调色仅用于当前模式、主新增操作和主保存操作；其余控件使用系统语义色。保持紧凑、高频工具属性，不增加营销式装饰。

## 布局与尺寸

- 面板内容外边距：10pt。
- 标题、内容、底部工具栏之间：8pt。
- 内容区内边距：8pt。
- 图标按钮：28×28pt，圆角 9pt，按钮间距 6pt。
- 文件夹和条目行：30pt。
- 标题、内容和工具栏模块圆角：12pt。
- 标题模块 40pt，底部工具栏 36pt。

## 新增交互

- 内容区左上角显示主新增和新建文件夹两个纯图标按钮。
- 主新增使用 `plus`，文件夹使用 `folder.badge.plus`。
- 常态不显示解释文字；通过 tooltip 和辅助功能标签说明用途。
- 空文件夹保留上下文新增按钮，但使用与顶部一致的图标组件。
- 点击新增后，32pt 操作槽扩展为内嵌编辑卡片；列表保持原位置。
- 保存或取消后恢复图标操作槽。

## 视觉约束

- 使用 AppKit 系统材质和语义颜色，不手绘高饱和渐变或氛围光。
- 表面只保留细边框与轻层次，不叠加多层重阴影。
- 所有模式共享相同模块尺寸、间距和圆角。
- 深浅色、降低透明度与高对比度环境下保持可读。

## 验收

- 底部不出现新增入口。
- 片段和密码箱的新增组件尺寸一致。
- 所有主模块之间保持 8pt 间距，内容内边距为 8pt。
- 图标按钮为 28×28pt；列表行为 30pt。
- 截图确认普通态、hover/tooltip、编辑态没有不齐、拥挤或尺寸跳变。
