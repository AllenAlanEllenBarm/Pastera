# 主菜单文件夹与条目编辑排序设计

## Goal

统一密码箱与片段模块的编辑交互：默认以浏览模式打开，在编辑模式中允许文件夹折叠、文件夹排序、条目排序和跨文件夹移动，并在列表底部提供稳定的新建文件夹入口。

## Scope

本设计覆盖主菜单内嵌的密码箱和片段模块，包括：

- 每次进入模块时默认处于浏览模式。
- 编辑模式不强制展开文件夹；最多展开一个文件夹，同时允许全部收起。
- 编辑模式在文件夹列表最底部显示一个 `+ 新建文件夹` 入口，且不受当前展开状态影响。
- 文件夹可拖拽调整顺序。
- 密码条目和片段可在当前文件夹内排序，也可拖入其他文件夹并放到指定位置。
- 排序与归属变更持久化；重新进入模块后使用保存后的顺序。

本设计不改变密码复制、粘贴、解锁、身份验证、片段执行、搜索和同步等既有业务语义，也不新增独立编辑窗口。

## Interaction Model

### 浏览模式

- 模块首次进入和再次打开时均为浏览模式。
- 隐藏拖拽把手、重命名、删除和 `+ 新建文件夹` 入口。
- 文件夹使用手风琴行为：同一时间最多展开一个，点击已展开文件夹可将其收起，因此允许全部收起。
- 密码条目和片段保留现有点击、双击、快捷键与右键操作。

### 编辑模式

- 点击现有编辑按钮进入编辑模式；退出后不记忆编辑状态。
- 文件夹仍可自由展开和收起，不因进入编辑模式被锁定为展开状态。
- 文件夹行显示拖拽把手、重命名和删除操作；条目行显示适合其层级的编辑操作与拖拽反馈。
- 文件夹列表末尾只显示一个紧凑的 `+ 新建文件夹` 入口。入口属于列表级操作，不重复出现在每个文件夹下方。
- 新建文件夹追加到文件夹列表末尾，并立即进入现有的内联命名流程。

### 拖拽规则

- 文件夹只能在文件夹层级重新排序，不能成为其他文件夹的子项。
- 条目可在当前文件夹内重新排序。
- 条目可拖到另一个文件夹的指定位置；放下后同时更新其文件夹归属和目标顺序。
- 拖拽悬停在已收起的目标文件夹上约现有 `folderHoverOpenDelay` 时，目标文件夹自动展开，便于选择插入位置。
- 拖拽期间使用插入线表达具体位置，使用文件夹高亮表达可接收的目标；无效目标不显示可放置状态。
- 取消拖拽或持久化失败时恢复拖拽前的界面顺序，并保留当前编辑模式。

## Architecture

`MainMenuPanelController` 继续拥有模块模式、编辑状态、展开文件夹和拖拽会话的界面状态，避免将状态分散到临时行视图中。密码箱与片段模块共享交互规则和轻量的拖拽位置计算方式，但继续调用各自的数据源接口，不引入跨业务仓库的统一持久层。

片段模块复用 `SnippetRepository` 已有的文件夹索引更新、片段索引更新和跨文件夹移动能力。密码箱数据源与 store 增加对等的文件夹排序、条目排序及跨文件夹定点移动接口；KDBX 快照保存仍是这些变更的唯一持久化出口。

一次拖拽提交必须表达完整的目标顺序。控制器先保留旧快照并显示乐观排序结果，数据源保存成功后刷新权威快照；保存失败则恢复旧快照并显示现有风格的错误反馈。

## State and Data Flow

1. 进入密码箱或片段模块时，将编辑状态重置为 `false`，展开状态保持为单选可空。
2. 用户进入编辑模式后，控制器构建带编辑操作、拖拽类型和列表底部新增入口的行模型。
3. 拖拽开始时记录对象 ID、来源文件夹、来源索引及拖拽前顺序。
4. 拖拽经过目标行时计算文件夹目标索引或条目目标文件夹与目标索引，并更新插入反馈。
5. 放下后调用对应数据源的单次重排操作。
6. 成功后以仓库快照重建列表；失败后恢复旧顺序并展示错误。

## Error Handling

- 删除中的对象、已不存在的对象或不属于当前快照的拖拽数据视为无效，不修改持久化数据。
- 不允许把文件夹拖入自身，也不允许把条目放到文件夹层级之外。
- 写入失败时不部分保存源文件夹或目标文件夹顺序；跨文件夹移动必须作为一个原子业务操作完成。
- 拖拽期间若模块退出、锁定或数据源刷新，则取消当前拖拽并使用最新权威快照。

## Accessibility and Visual Behavior

- 拖拽把手使用一致的 SF Symbol 和至少 24pt 的可见尺寸，并通过行内命中区域满足 macOS 可操作性要求。
- 文件夹展开状态、编辑状态和可放置状态不能仅依靠颜色表达。
- `+ 新建文件夹` 提供明确的 accessibility label；键盘用户仍可通过现有焦点系统进入并触发。
- 插入线、悬停展开和目标高亮沿用当前深色表面与设计 token，不引入 Web 风格拖拽外观。

## Acceptance Criteria

- 密码箱与片段模块每次进入时均为浏览模式。
- 编辑模式下可以展开一个文件夹、将其收起至全部折叠，并再次展开任意文件夹。
- 编辑模式下列表末尾始终有且只有一个 `+ 新建文件夹` 入口；浏览模式不显示该入口。
- 新建文件夹追加到末尾并进入内联命名流程。
- 文件夹拖拽后顺序立即更新，重新进入模块后顺序不变。
- 密码条目和片段均可在文件夹内部排序，也可移动到另一个文件夹的指定位置；重新进入后归属和顺序不变。
- 悬停在收起文件夹上会自动展开；取消拖拽不改变数据。
- 持久化失败不留下部分移动或错误顺序。
- 密码箱原有解锁、复制、粘贴、编辑、删除与身份验证行为保持不变；片段原有执行与编辑行为保持不变。

## Verification

- 控制器测试覆盖默认浏览模式、编辑模式折叠、单一底部新增入口、拖拽位置计算、悬停展开和失败回滚。
- `SnippetRepository` 测试覆盖文件夹排序、文件夹内片段排序以及跨文件夹定点移动。
- 密码箱 store 测试覆盖文件夹排序、文件夹内条目排序、跨文件夹原子移动及重新加载后的持久化结果。
- 主菜单回归测试确认浏览模式的点击、快捷键和右键行为没有被拖拽注册破坏。
- 完成实现后执行聚焦测试、仓库默认 macOS 测试、`git diff --check` 和本地安装，再在真实面板中人工验证两套模块的拖拽与折叠行为。

## Out of Scope

- 多选拖拽和批量移动。
- 文件夹嵌套。
- 跨密码箱与片段模块拖拽。
- 自定义排序规则、按名称自动排序或撤销历史。
- 改造密码箱解锁流程、片段编辑器或主菜单整体视觉风格。
