# Pastera 设置中心重构设计

## 目标

将现有紧凑偏好设置重构为宽幅、可搜索、分组清晰的 AppKit 设置中心，同时保留现有偏好键、OneDrive、Sparkle、KeyHolder、历史数据和同步协议。

## 信息架构

侧栏固定为六页：

1. 通用：开机启动、菜单透明度、标题长度、颜色预览、自动粘贴、远程控制时暂停快捷键。
2. 历史与预览：图片/文件数量限制、重复项策略、保存类型、文件预览类型、清空历史。
3. 快捷键：菜单快捷键、历史面板快捷键及分组恢复默认。
4. 排除应用：应用图标、名称、路径、添加和删除。
5. 同步：OneDrive 状态、同步位置、文件类型、手动同步及四个上传/导入开关。
6. 关于 Pastera：图标、版本、构建号、GitHub 入口、MIT License 与 Sparkle 更新设置。

侧栏分为“使用偏好”和“服务与支持”。不增加置顶图钉、独立快捷键启用开关或尚不存在的功能入口。

## 窗口与搜索

- 默认尺寸 `760×600`，最小尺寸 `680×480`，宽度可调整并通过 frame autosave 跨启动恢复。
- 搜索匹配本地化标题、说明和关键词，标题权重高于说明和关键词，不访问数据库、文件或网络。
- 结果按页面分组，仅用于导航。点击结果后进入目标页面、滚动到稳定 Anchor ID，并高亮约 1 秒。
- `⌘F` 聚焦搜索；搜索非空时 `Esc` 清空并返回原页，再次 `Esc` 关闭窗口。
- 页面切换使用约 120ms 淡入；开启“减少动态效果”时取消动画。

## 设置行为

- 开关、滑杆、选择器、保存类型和快捷键即时写入。
- 数字输入在 `Return` 或失焦时提交。空白或非数字保留草稿并显示行内错误，`Esc` 恢复最近有效值；可解析但越界的值按现有上下限规范化。
- 自动粘贴采用权限先行：未获辅助功能权限时开关保持关闭，显示说明和“打开系统设置”，不写入启用状态。
- 快捷键保留“录制即启用、清空即停用”，仅新增两组恢复默认操作，不显示确认弹窗。
- 清空历史位于危险操作区，沿用现有确认面板。
- 同步路径、同步协议、文件类型和上传/导入语义不变。

## 实现边界

- 使用 AppKit 代码布局和共享页面、分组、设置行、状态组件，不引入 SwiftUI 或第三方依赖。
- 页面目录与搜索元数据显式注册；页面通过 `PasteraPreferencePage` 暴露 Anchor 定位。
- 旧 XIB 页面在对应代码页面验证通过后删除；旧布局归一化和对齐适配器在无引用后删除。
- 原有德语、意大利语、日语和简体中文翻译迁移到 `Localizable.xcstrings`。

## 验收

- 六页结构、搜索定位、即时写入、权限拒绝、输入校验、快捷键重置、清空确认、同步和更新操作均有自动化测试。
- 默认、最小和宽窗口无裁切，深浅色与减少动态效果可用。
- 完整 `xcodebuild clean test` 通过，随后安装到 `/Applications/Pastera.app` 供人工检查。
