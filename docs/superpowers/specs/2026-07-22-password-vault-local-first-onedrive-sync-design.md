# Pastera 密码箱本地优先与 OneDrive 可选同步设计

## 状态

- 设计状态：已确认
- 确认日期：2026-07-22
- 交互简化修订：已确认（2026-08-04）
- 产品方向：本地优先，OneDrive 作为可选同步副本
- 离线策略：断联期间允许完整新增、修改和删除
- 交互边界：主界面 OneDrive 图标只表示客户端与同步状态，并负责打开或激活 OneDrive；账户、根目录、单向启用和手动同步留在设置页；只有本地副本缺失、远端主密码或冲突副本等上下文恢复继续出现在密码箱页面

## 背景与问题

当前密码箱把配置在 OneDrive 中的 KDBX 文件作为唯一工作文件。用户提交主密码时，程序会先读取 OneDrive 文件；如果 OneDrive 未运行、文件仍是云端占位符、目录失效或 File Provider 返回错误，密码校验尚未开始，界面却会在密码输入框下显示 OneDrive 错误。

该设计造成四个产品问题：

1. 用户会把同步故障误解成密码错误。
2. 没有 OneDrive 或不希望使用 OneDrive 的用户无法自然使用密码箱。
3. OneDrive 断联会阻断本应属于本机的解锁、读取和编辑操作。
4. 用户不知道断联期间的数据是否安全、恢复连接后是否会被覆盖。

本设计不再把云盘可用性作为密码箱可用性的前置条件，而是把本地密码箱与同步状态拆成两个独立维度。

## 产品目标

- 没有安装、登录或启用 OneDrive 时，密码箱仍能完整创建和使用。
- 默认提供“仅保存在本机”，不得自动启用 OneDrive。
- OneDrive 断联时，密码箱仍能解锁、查看、复制、新增、修改和删除。
- 所有本地操作立即保存到本地加密 KDBX，不等待网络或 File Provider。
- 恢复连接后按条目双向合并，不使用整库最后写入覆盖。
- 任何无法自动判断的修改都保留为冲突副本，不静默丢失。
- 用户能从主界面图标与设置摘要理解 OneDrive 客户端、密码箱同步、待同步更改和最近同步结果。
- OneDrive 状态不得再显示成密码输入错误。
- 不在产品界面提供停止密码箱同步或删除 OneDrive 副本。

## 非目标

- 本期不增加 iCloud、Dropbox、Google Drive 或自建服务。
- 本期不更改 KDBX 加密格式、主密码、Keychain 或自动锁定策略。
- 本期不实现 Windows 客户端，但数据和同步语义不得阻碍后续跨平台实现。
- 本期不把密码条目明文写入同步队列、UserDefaults、日志或诊断文件。
- 本期不要求用户理解 File Provider、占位文件或文件协调器等底层概念。

## 核心产品原则

### 本地是工作副本

密码箱的创建、解锁、读取和编辑始终针对本地加密 KDBX。OneDrive 只保存可选的加密同步副本，不参与主密码验证。

### 同步不阻断使用

同步失败只改变同步状态，不改变密码箱可用状态。只要本地 KDBX 可读，OneDrive 断联、未安装、未登录、空间不足或目录不可写都不能阻止本地操作。

### 不静默覆盖

恢复连接时先比较本地、云端与最近同步基线。只有一端变化时自动同步；两端变化时执行条目级合并；无法判断时保留冲突副本。

### 用户主动选择 OneDrive

首次创建默认选择“仅保存在本机”。检测到 OneDrive 只能作为可选能力展示，不能自动移动密码箱或开启同步。

密码箱同步一旦启用，产品界面不再提供切回仅本机或删除云端副本。该约束只删除用户可触发的破坏性/分叉操作，不改变本地优先、离线编辑、自动恢复和冲突保护。

### 明确选择 OneDrive 账户

- 只有名称精确为 `OneDrive` 的个人根目录允许自动选择。
- `OneDrive-*` 可能是工作账户、共享资料库或本地化名称；即使只有一个候选也必须由用户在设置页明确选择。
- 已知共享资料库与 `CloudTemp` 目录不进入可选候选。至少覆盖 `OneDrive-Shared Libraries-*` 与 `OneDrive-共享的库-*`。
- 已保存根目录不存在、属于共享资料库或未通过写入/回读/删除探针时，停止新的云端写入并要求重新选择；不得删除本地或云端数据。

## 数据架构

### 本地密码箱

- 本地 Application Support 目录保存唯一工作 KDBX。
- 文件继续使用现有 KDBX 加密和原子写入机制。
- 每次成功写入前保留加密备份，失败时不替换最后一个可读版本。
- 主密码、派生密钥和解密内容继续遵循现有会话与 Keychain 生命周期。

### OneDrive 同步副本

- OneDrive 中只保存加密 KDBX 和必要的非敏感同步元数据。
- 云端副本不是运行时工作文件；本地操作不直接写 OneDrive 路径。
- 云端读取、写入、校验失败不得破坏或回滚已经成功保存的本地修改。

### 同步元数据

允许本地保存以下不包含密码内容的状态：

- 当前本地修订号。
- 最近成功同步的本地修订号。
- 最近观察到的云端加密文件摘要。
- 最近成功同步时间。
- 是否存在待同步更改及其数量。
- 最近同步错误类别。

不得在独立同步队列中保存账号、密码、备注或其他条目明文。待同步内容以本地加密 KDBX 为准。

## 独立状态模型

### 密码箱状态

| 状态 | 含义 | 用户能力 |
| --- | --- | --- |
| 未创建 | 本机没有密码箱 | 创建本地密码箱 |
| 已锁定 | 本地 KDBX 可用但未解锁 | 输入主密码或快速解锁 |
| 解锁中 | 正在读取和解密本地 KDBX | 等待，控件保持响应 |
| 已解锁 | 本地密码箱正常 | 完整使用 |
| 只读警告 | 本地写入发生可恢复问题 | 查看、复制、执行恢复 |
| 本地损坏 | 本地 KDBX 无法读取 | 从本地备份或云端恢复 |

### 同步状态

| 状态 | 视觉表达 | 对密码箱的影响 |
| --- | --- | --- |
| 未启用 | 图标颜色表示客户端是否运行，辅助文字说明“密码箱同步未开启” | 无影响 |
| 已同步 | 客户端运行时使用蓝色 OneDrive 图标，辅助文字包含最近同步时间 | 无影响 |
| 同步中 | 蓝色进度状态，文字说明当前步骤 | 无影响 |
| 已断联 | OneDrive 图标加红色断联徽标 | 无影响，本地完整可用 |
| 等待解锁合并 | 红色或黄色状态文字，说明需要解锁 | 解锁前只暂停同步 |
| 有冲突副本 | 黄色提醒及冲突数量 | 无影响，可稍后整理 |
| 云端写入失败 | 红色状态与可执行修复动作 | 本地修改保留并继续累计 |

密码箱状态和同步状态必须组合展示，不得互相替代。例如“密码箱已锁定 + OneDrive 已断联”是合法组合，用户仍能通过本地文件验证主密码。

## 用户场景

### 场景一：从不使用 OneDrive

1. 用户进入密码箱创建页面。
2. 页面先展示保存方式，“仅保存在本机”为默认选项。
3. 用户设置主密码并创建本地加密 KDBX。
4. 后续不显示同步错误；底部 OneDrive 入口保持中性并标注“同步未开启”。
5. 用户可随时在设置页选择 OneDrive 账户并单向开启密码箱同步。

### 场景二：首次开启同步，云端没有密码箱

1. 用户主动选择“使用 OneDrive 同步”。
2. Pastera 校验 OneDrive 目录和写入能力。
3. 页面说明将创建本地密码箱的加密同步副本。
4. 上传成功并校验摘要后，状态变为“已同步”。
5. 上传失败时继续使用本地密码箱，并显示可重试的同步状态。

### 场景三：首次开启同步，云端已有密码箱

1. 页面显示“发现两个密码箱”。
2. 同时展示本地和 OneDrive 的条目数量、更新时间和可用状态。
3. 主操作为“合并并开启同步”，说明不会直接替换任何一边。
4. 用户可以返回并继续仅本机使用。
5. 合并完成后写入本地，再上传云端并校验。

### 场景四：OneDrive 突然中断

1. 底部 OneDrive 图标增加明显的红色断联徽标。
2. 当前密码箱页面使用非阻塞状态说明：“同步已暂停，仍可在本机使用”。
3. 解锁、查看、复制、新增、修改和删除继续正常。
4. 每次操作成功写入本地后增加待同步计数。
5. 点击 OneDrive 图标：未运行时启动客户端，已运行时激活客户端；不切换密码箱页面。

### 场景五：恢复连接，只有一端变化

- 只有本地变化：确认云端摘要未变化后上传本地加密 KDBX。
- 只有云端变化：下载、校验并更新本地 KDBX。
- 完成后更新同步基线并清除待同步计数。
- 全过程不要求用户确认。

### 场景六：恢复连接，两端同时变化

1. 下载并校验云端加密 KDBX。
2. 如果密码箱已解锁，立即执行条目级合并。
3. 如果密码箱已锁定，状态变为“等待解锁以完成合并”，不得覆盖任一端。
4. 用户解锁后继续合并。
5. 先原子写入本地和本地备份，再上传云端。
6. 云端写入和摘要校验成功后才清除待同步状态。

### 场景七：新设备没有本地副本

1. 如果云端可用，先下载和校验加密 KDBX，再显示主密码输入。
2. 如果云端不可用，不显示密码错误，也不要求用户反复输入主密码。
3. 当前窗口显示“本地密码箱尚未准备好”，提供“启动 OneDrive”“重试”和“继续仅本机创建新密码箱”。
4. 创建新密码箱前必须说明可能形成独立数据分支。

## 合并与覆盖规则

### 基线判断

同步使用“本地修订 + 最近同步云端摘要 + 当前云端摘要”判断变化来源：

- 本地修订未变化、云端摘要变化：云端更新。
- 本地修订变化、云端摘要未变化：本地更新。
- 两者都变化：双向合并。
- 两者都未变化：无操作。

### 条目级合并

- 以密码条目 UUID 为身份。
- 不同条目的修改直接合并。
- 同一条目两端都变化时，以修改时间较新的版本为当前版本，另一版本写入 KDBX 历史。
- 修改时间一致但内容不同，生成新的冲突条目并在标题中标注“冲突副本”。
- 文件夹使用相同的 UUID 与修改时间原则。
- 删除使用 KDBX tombstone；删除时间晚于条目修改时间时才执行删除。
- 合并结果不得因为排序差异产生无意义冲突。

### 写入顺序

1. 验证本地当前版本和云端输入版本。
2. 生成合并后的加密 KDBX。
3. 保存本地加密备份。
4. 原子替换本地工作 KDBX。
5. 上传 OneDrive 临时文件。
6. 原子替换云端副本并重新读取摘要。
7. 摘要一致后更新同步基线和状态。

任一步失败时不得删除本地成功版本，也不得把待同步状态误报为完成。

## 主窗口交互设计

### 创建密码箱

在设置主密码前展示保存方式：

- “仅保存在本机”：默认选中，说明“不需要 OneDrive，以后可以随时开启同步”。
- “使用 OneDrive 同步”：说明“可在其他设备使用，断联时仍可完整编辑”。

Pastera 不得因为检测到 OneDrive 已安装就默认选择同步。

### 密码解锁页面

- 密码输入框下方只显示密码验证相关错误。
- 只有本地 KDBX 已成功读取且 KDBX 解析明确返回凭据错误时，显示“主密码不正确”。
- OneDrive 断联使用输入框外的非阻塞状态区，文案为“同步已暂停，仍可在本机使用”。
- 本地副本尚未准备好时，用同步恢复页面替代密码输入表单。

### 底部 OneDrive 入口

- OneDrive 已运行：蓝色图标；点击激活 OneDrive。
- OneDrive 未运行但已安装：中性图标；点击启动 OneDrive。
- OneDrive 未安装：中性不可启动状态；辅助文字说明未安装，不自动打开下载页。
- 密码箱同步未启用：辅助文字补充“密码箱同步未开启”，但不覆盖客户端运行状态。
- 已同步：辅助文字包含最近同步时间。
- 同步中：蓝色进度状态，遵循减少动态效果设置。
- 已断联：图标右上角显示红色断联徽标；不能只依赖颜色。
- 有冲突：黄色提醒和冲突数量。
- 点击后不导航到密码箱同步页面，不打开弹框、浮层或向导。

### 设置页 OneDrive 区域

设置页保留：

- OneDrive 客户端状态、当前根目录和更换账户动作。
- 密码箱同步模式、待同步数量、最近同步时间和最近失败摘要。
- 通用“立即同步”。
- localOnly 时的单向“启用密码箱 OneDrive 同步”；启用后不显示停止或删除动作。

设置页不得再显示“在主窗口管理”。多账户或只有 `OneDrive-*` 候选时必须显式选择；不得静默选择排序后的第一个目录。

### 上下文恢复页面

仅以下状态保留密码箱内部页面：

- 新设备本地副本尚未准备好：显示启动 OneDrive、重试和数据分支警告。
- 云端密码箱使用不同主密码：显示一次性远端安全输入。
- 合并生成冲突副本：显示冲突摘要和筛选入口。

普通同步成功、断联或写入失败不再打开长同步面板。

### 冲突结果页面

- 自动合并完成后只在存在冲突时显示黄色非阻塞提醒。
- 告知自动合并数量、冲突副本数量和剩余待同步数量。
- 提供“查看冲突副本”和“返回密码箱”。
- 冲突不得锁定密码箱，也不得要求用户立即处理。

## 文案规范

推荐文案：

- 仅本机：“仅保存在本机”。
- 已同步：“OneDrive 已同步”。
- 断联：“OneDrive 已断开”。
- 断联说明：“同步已暂停，仍可在本机使用。3 项更改将在恢复连接后同步。”
- 本地安全：“本地密码箱安全可用”。
- 等待解锁：“需要解锁密码箱以合并两端更改”。
- 本地副本缺失：“本地密码箱尚未准备好”。
- 密码错误：“主密码不正确”。

禁止文案：

- 在密码框下显示“The configured OneDrive folder is unavailable.”。
- 向用户暴露 File Provider、错误码、路径或占位文件概念。
- 使用“云端异常，密码箱不可用”概括仍有可用本地副本的状态。

## 可访问性

- 红色、黄色和蓝色必须同时配合徽标、文字和辅助功能标签。
- OneDrive 图标的 accessibility label 包含连接状态和待同步数量。
- 页面内模式选择、主要动作和返回动作支持完整键盘导航。
- 动态同步进度遵循“减少动态效果”；关闭动画后使用静态进度和文字。
- 状态变化使用适度的辅助功能公告，不连续播报每个同步子步骤。
- 主密码和密码条目不得进入 accessibility value、日志或同步状态文案。

## 安全与隐私

- 本地和 OneDrive 始终只持久化加密 KDBX。
- 同步元数据不得包含账号、密码、网址、备注或条目标题。
- 冲突诊断只记录匿名数量、修订和错误类别。
- 产品界面不提供停止同步或删除云端副本，避免误操作造成设备分叉或数据删除。
- 迁移和恢复必须保留最后一个可验证的加密备份。

## 迁移策略

现有版本以 OneDrive KDBX 为工作文件，升级时必须执行一次性迁移：

1. 读取当前同步根目录和云端 KDBX。
2. 如果文件可用，完整下载并验证 KDBX 结构和加密文件摘要。
3. 原子写入新的本地工作路径，并保留加密迁移备份。
4. 写入最近同步云端摘要和迁移完成标记。
5. 验证本地工作副本可读取后，才切换为本地优先模式。

如果 OneDrive 不可用：

- 保留旧配置和云端文件，不创建空密码箱覆盖它。
- 显示“需要先准备本地副本”，提供启动 OneDrive 和重试。
- 不显示密码错误。
- 用户明确选择创建新的仅本机密码箱时，说明将形成独立数据分支。

## 错误处理矩阵

| 错误 | 本地行为 | UI 状态 | 恢复动作 |
| --- | --- | --- | --- |
| OneDrive 未安装 | 本地继续使用 | 同步不可用 | 图标说明未安装；由用户自行安装 |
| OneDrive 未运行 | 本地继续使用并累计更改 | 红色断联 | 启动 OneDrive |
| 用户退出登录 | 本地继续使用并累计更改 | 红色断联 | 登录后重试 |
| 云端空间不足 | 本地继续保存 | 云端写入失败 | 清理空间并重试 |
| 同步目录无权限 | 本地继续保存 | 目录不可写 | 重新选择目录 |
| 云端文件损坏 | 不替换本地 | 需要恢复 | 使用本地版本重建云端副本 |
| 本地文件损坏 | 不上传损坏版本 | 本地恢复状态 | 从本地备份或云端恢复 |
| 主密码错误 | 不改变同步状态 | 密码框内错误 | 重新输入 |
| 两端变化且仍锁定 | 不覆盖任一端 | 等待解锁合并 | 解锁后继续 |

## 验收标准

### 本地模式

- 未安装 OneDrive 时可以创建、解锁和完整编辑密码箱。
- 首次创建默认选择“仅保存在本机”。
- 未启用同步不会显示红色错误或断联徽标。
- 检测到 OneDrive 不会自动开启同步或移动密码箱。

### 断联模式

- 终止 OneDrive 进程后，本地解锁、查看、复制、新增、修改和删除继续成功。
- 每次成功本地写入增加待同步状态。
- 密码输入框不显示 OneDrive 错误。
- 底部 OneDrive 图标显示红色断联徽标和可读辅助标签。
- 点击图标启动或激活 OneDrive，不切换密码箱页面，不出现弹框或浮层。

### 恢复与合并

- 只有本地变化时上传，只有云端变化时下载。
- 两端变化时按条目合并，不执行整库最后写入覆盖。
- 同一条目冲突保留 KDBX 历史或冲突副本。
- 删除 tombstone 不会错误删除更新更晚的条目。
- 云端写入验证成功前不清除待同步状态。
- 锁定状态下无法安全合并时等待解锁，不覆盖任何一端。

### 账户与操作简化

- 精确个人根目录 `OneDrive` 可自动选择；任何 `OneDrive-*` 候选要求用户明确选择。
- 本地化共享资料库不会被静默选为写入根目录。
- 设置页允许 localOnly 单向启用密码箱同步，启用后不出现停止同步或删除云端副本。
- 主界面不再存在通用密码箱同步状态长页面或“在主窗口管理”入口。

### 迁移

- 旧版云端工作 KDBX 在切换前成功下载、验证并写入本地。
- 迁移失败时旧云端文件和配置保持不变。
- File Provider 错误不会被映射为主密码错误。

## 实施边界

后续实施计划应至少拆成以下阶段：

1. 建立本地工作 KDBX 与旧版迁移边界。
2. 拆分密码箱状态和同步状态。
3. 实现断联期间本地写入和待同步修订。
4. 实现云端摘要判断、双向合并与冲突副本。
5. 实现 OneDrive 客户端入口、首次/设置页选择、断联徽标和必要恢复页面。
6. 完成本地模式、断联、恢复、冲突、迁移、账户选择和真实 OneDrive 验证。

在该设计规格获得最终审阅前，不进入代码实现。
