# Pastera 密码箱上下文快捷操作设计

## 目标

移除密码箱顶部常驻快捷键说明卡，将账号和密码粘贴能力放回当前密码条目，使操作更紧凑、可发现且不打断文件夹层级。

## 设计判断

这是现有 macOS 菜单栏产品的局部保留式重设计。延续暗色、中高密度、紧凑圆角和 SF Symbols 视觉语言，不新增弹窗、独立面板或高饱和强调色。

设计参数：

- 变化度：4
- 动效强度：2
- 视觉密度：7

## 交互规则

### 普通模式

- 密码箱顶部不再显示任何常驻快捷键说明。
- 密码条目未选中且鼠标未悬停时，只显示图标和标题。
- 密码条目被键盘选中或鼠标悬停时，在右侧显示三个图标按钮：
  1. 账号图标：立即粘贴账号。
  2. 钥匙图标：立即粘贴密码。
  3. 更多图标：打开该条目的完整上下文菜单。
- 三个按钮均使用原有账号、密码粘贴链路，不复制明文到普通历史。
- Return 复制密码、双击编辑、右键菜单和 ⌥⌘U / ⌥⌘P 快捷键继续有效。
- 按钮 Tooltip 和辅助功能标签包含动作名称及快捷键。

### 编辑模式

- 密码条目不显示账号、密码和更多按钮。
- 当前删除按钮保持原有行为。
- 文件夹和密码创建、编辑、删除流程不受影响。

### 首次引导

- 每台设备第一次选中密码条目时，在密码箱内容区底部覆盖轻量提示“右侧可快速粘贴”。
- 提示不占列表行、不改变滚动位置、不遮挡工具栏，约 2 秒后淡出。
- 展示状态写入本机 UserDefaults，不参与同步。
- 之后依靠就地按钮、Tooltip、上下文菜单和辅助功能标签提供持续可发现性。

## 视觉规则

- 使用现有 20 点附件按钮尺寸、次级文字色和悬停行背景。
- 使用 SF Symbols，不添加自绘图标或新依赖。
- 操作区只在当前行强调状态出现，避免所有条目同时产生视觉噪音。
- 标题优先保留可读空间，宽度不足时尾部截断。
- 不使用新的卡片、阴影、渐变、徽章或说明段落。

## 可访问性

- 鼠标悬停和键盘选择触发相同可见状态。
- 每个按钮具有明确的 accessibility label、help 和 Tooltip。
- 更多按钮打开与右键相同的 NSMenu。
- 不依赖颜色区分按钮状态。

## 验收标准

- 有密码条目时顶部说明行不存在。
- 未选中条目不显示快捷操作。
- 选中或悬停条目显示三个快捷操作，点击分别执行正确动作。
- 更多按钮显示原有完整菜单。
- 切换编辑模式后快捷操作消失，删除按钮出现。
- ⌥⌘U、⌥⌘P、Return、双击和右键行为回归通过。
- 首次引导只显示一次且不会改变列表几何布局。
- 同尺寸截图中不存在顶部大块说明，文件夹和条目成为内容区第一视觉层级。
